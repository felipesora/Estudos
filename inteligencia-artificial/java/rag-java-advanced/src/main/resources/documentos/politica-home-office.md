# Política de Home Office

## Horário

Os colaboradores em regime de home office devem cumprir
a jornada estabelecida pelo contrato de trabalho.

O horário de almoço deve ser respeitado conforme as regras
da empresa.

## Equipamentos

Os equipamentos fornecidos pela empresa devem ser utilizados
prioritariamente para atividades profissionais.

O colaborador deve manter os equipamentos protegidos contra
acesso de terceiros.

## Segurança

O colaborador não deve utilizar redes Wi-Fi públicas para
acessar sistemas corporativos sem utilizar os mecanismos
de segurança fornecidos pela empresa.
