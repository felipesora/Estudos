# Política de Segurança

## Senhas

As senhas corporativas devem possuir no mínimo 12 caracteres.

As senhas devem conter letras maiúsculas, letras minúsculas,
números e caracteres especiais.

Os usuários não devem reutilizar senhas utilizadas anteriormente.

As senhas devem ser alteradas imediatamente caso exista suspeita
de comprometimento da conta.

## Autenticação

Todos os sistemas corporativos que suportam autenticação
multifator devem utilizar MFA.

O segundo fator pode utilizar aplicativo autenticador,
chave de segurança ou outro mecanismo aprovado pela equipe
de segurança da informação.
